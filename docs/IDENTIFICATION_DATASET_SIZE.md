# 식별 에이전트 v2 데이터 규모의 선정 근거

## 결정의 성격

역할별 학습 4,096 / 검증 1,024 / 시험 1,024는 **사전에 정한 실험 예산**이다.
이 수가 최적이라는 실험 결과나 일반화 보장은 없다. 2의 거듭제곱이라는 사실은
통계적 근거가 아니며, GPU 메모리도 데이터 전체 건수가 아니라 배치·길이에 좌우된다.

학습은 기존 512에서 1,024·2,048·4,096으로 두 배씩 확장하는 비교 격자를 설정했다.
배증 설계는 상대적인 데이터 증가량을 일정하게 하고 학습 비용·검증 성능의 변화를
비교하기 위한 것이다. 4,096은 이번 후보 상한이며, 학습 곡선이 실행되기 전에는
데이터 확대의 효과가 입증되었다고 쓰지 않는다. 계획과 실행 결과는 구분한다.

검증 1,024는 모델·학습 설정 선택을 위한 고정 분할, 시험 1,024는 최종 비교를 위한
분할이다. 기존 64보다 사례 범위를 넓히고 오답 한 건의 영향(1/64 대 1/1024)을
줄이려는 운영상 선택이다. 모집단 오차 범위를 만족하도록 산출한 표본 수는 아니다.
NVD 파생·합성 데이터이므로 건수가 늘어도 실제 현장 분포의 대표성은 확보되지 않는다.

## 실제 표본 수와 반복

| 역할 | 학습 행 / 고유 입력 | 검증 행 / 고유 입력 | 시험 행 / 고유 입력 |
|---|---:|---:|---:|
| L2 | 4,096 / 4,033 | 1,024 / 1,017 | 1,024 / 1,017 |
| L3 | 4,096 / 4,033 | 1,024 / 1,017 | 1,024 / 1,017 |
| L4 | 4,096 / 4,096 | 1,024 / 1,024 | 1,024 / 1,024 |

기존 v1의 빈 이름과 NOASSERTION 반복을 보존해 L2/L3에 일부 중복이 남았다.
새로 추가한 행은 이 상수를 반복해서 건수를 채우지 않는다. 반복 입력은 독립적인
새 표본이라고 주장하지 않는다. 라벨 분포도 `audit.json`에 기록되어 있다.
L4는 유보 사례가 많으므로 전체 정답률 외에 확정 Precision·판정률·유보율을 함께 본다.

## 분리·보존 정책

- v1의 모든 행을 원래 분할에 그대로 보존한다. 이전 시험 행이 새 학습에 들어가지 않는다.
- 추가 행은 구분 기호를 제거한 제품 키, 원본 버전의 선행 v를 정리한 그룹도 분리한다.
- 비어 있지 않은 L2 이름의 정규화 중복과 L4 입력 중복도 분할 사이에서 검사한다.
- 빈 이름/NOASSERTION 같은 보편적 유보 표식은 예외로 명시하며 숨기지 않는다.
- 파일 SHA-256, 원본 SHA-256, 라벨 분포, 고유 입력 수, 기존 행 보존 결과를 저장한다.

시험 1,024건에는 이미 v1에서 평가한 64건과 새 960건이 포함된다. 따라서 모두
처음 본 시험이라고 표현하면 안 된다. v2 학습 보고서는 두 구간의 성능을 별도로
기록한다. 확대 데이터로 학습한 모델과 v1 모델을 비교하려면 동일한 v2 분할을
사용해야 하며, 예전 64건 점수와 새 1,024건 점수의 차이를 학습 효과로 해석하지 않는다.

## 학습 곡선 실행과 최종 평가

`learning_curve_subsets.json`에 역할별 512/1,024/2,048/4,096의 중첩된 학습 행 ID가
있다. 작은 집합은 큰 집합에 포함되며 검증 분할은 고정한다. 예:

```powershell
python tools/train_identification_agents.py --data data/identification_agents_v2 --train-limit 1024 --validation-only --out models/identification-curve-1024 --reports results/identification-curve-1024
```

이 후보 비교는 시험 출력을 생성하지 않는다. 검증 성능과 실제 학습 시간으로
설정을 선택한 다음, 고정한 최종 설정에 대해 시험을 수행한다. 독립 검토한 실제
SBOM 평가는 이 절차와 별개이며 아직 마련되지 않았다.

현재 4,096건 실행은 상한 후보의 1차 재학습이다. 규모별 곡선이 모두 끝났다는
의미가 아니며, 실측 기록이 없는 후보는 계획으로만 표시한다.
