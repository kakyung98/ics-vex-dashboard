# #4 실제 CVE 기반 합성 운영맥락 평가

## 무엇을 평가하는가

고정 모집단은 실제 CVE **12,418개**다. 기존 가상 CVE 100개 논리 시험을 이 모집단의 성능으로 사용하지 않는다. 새 데이터는 각 CVE의 원문·제품·선택 경로·조건·관측 상태를 추적한다.

이 평가는 **원문 조건부 합성 세계**의 판단을 측정한다. 원문에서 자동 추출한 초안의 의미 정확도나 실제 설비의 영향 정확도를 측정하는 실증 평가는 아니다. 다음 가정은 현실의 사실로 승인한 것이 아니라 합성 세계의 정의다.

* 원문이 설명한 선택 경로를 이 세계에서는 완전한 경로로 취급한다.
* 선택한 원문 제품 후보에 해당 경로가 적용된다고 가정한다.
* 운영자가 관측할 수 없는 전제는 이 세계에서 충족됐다고 명시한다. 운영자에게 공격자의 실제 자격증명·익스플로잇·메모리 상태를 증명하도록 요구하지 않는다.
* 다른 공격 경로는 이 합성 세계에서만 제외한다.

따라서 결과는 실제 CVE 전체의 비영향 또는 영향 결론으로 내보낼 수 없다. API는 `is_production_VEX=false`, `export_allowed=false`를 반환한다. 원문 초안의 `pending` 상태와 의미 검증 미완료 표시는 유지한다. 사람의 의미 검토 승인을 자동 생성하지 않는다.

## 별도 입력과 Gold

`benchmark/item4_source_context_gold_v2/`에 다음을 저장한다.

* `cve_source_records.jsonl`: 실제 CVE 12,418개 전체 원문·제품·초안. 원문 해시와 인용 위치를 보존한다.
* `cve_index.jsonl`: 모든 CVE의 분할·원문 경로·시험 사례 ID·미확정 사유.
* `train/inputs.jsonl`, `evaluation/inputs.jsonl`: 모델이 받을 수 있는 입력.
* `train/labels.jsonl`, `evaluation/labels.jsonl`: 모델에 전달하지 않는 독립 시뮬레이터 라벨.
* `manifest.json`, `integrity_audit.json`: 모집단·파일 해시·분할·원문 대조·정답 일관성·문맥 길이 검사.

총 **24,678건**, 원문 조건으로 합성 세계를 구성할 수 있는 CVE **2,452개**, 미확정 CVE **9,966개**다. 미확정 CVE는 삭제하지 않고 `under_investigation` 결정 라벨과 `actual_affected=null`을 가진 사례로 유지한다. 미확정 사유는 여러 개일 수 있으므로 사유별 수량은 합산 가능한 배타적 분류가 아니다.

관측 가능한 조건을 구별할 수 있는 경로마다 조건 충족/불충족, 숨겨진 충족/불충족, 충돌, 만료의 여섯 세계를 만든다. 서로 다른 숨겨진 실제 상태가 같은 관측을 만들 수 있다. 이런 사례에서 적절한 결정은 보류다. ID·구성 ID는 불투명하며 잠재 상태·정답·변형 이름을 모델 입력에 넣지 않는다.

`v1`은 기존 원문 초안 7개에서 같은 조건 ID를 네트워크와 인증 조건에 함께 사용한 문제를 발견해 격리했다. 학습·모델 시험 시작 전에 독립 관측 정답 검사로 발견했으며, `v2`는 이런 경로를 의미 재구성 필요 상태로 보존한다. 점수를 보고 고른 데이터 버전이 아니다.

## 독립 정답 생성과 판정기

Gold 생성기는 Boolean 식을 DNF로 컴파일하고 합성 세계의 잠재 상태에서 영향 여부를 계산한다. 관측 가능한 사실만으로 모든 가능한 숨겨진 상태를 열거해, 모든 경우에 선택 경로가 참일 때만 `A`를 정답 결정으로 삼는다. 그 밖에는 `U`다.

실행 판정기는 별도의 3값 AND/OR/NOT 논리와 범위·시점 검사를 사용한다. Gold 생성에 이 판정기의 결과를 쓰지 않는다. 전체 24,678건에서 두 구현의 결정 일치와 `A`가 잠재 상태의 참과 모순되지 않는지를 모델 학습 전에 검사했다.

두 구현의 일치는 선언한 합성 세계의 논리 정확성을 검사한다. 원문이 현실의 충분조건을 완전히 설명한다는 독립 검증은 아니다. 이 차이를 정밀도 수치와 함께 표시한다.

## 분할과 실제 QLoRA 학습

공유 원문 URL 연결 그룹을 유지한 기존 전체 모집단 분할을 쓴다. 학습 CVE **8,406개**, 시험 CVE **4,012개**다. 정확한 7:3이라고 표시하지 않는다. 두 구간의 CVE 및 선택 인용 문장 해시가 겹치지 않는 것을 검사했다.

새 #4 전용 어댑터는 학습 구간에서만 고정 해시 순서로 고른 **256개 예제**로 학습했다. `A/U` 각각 128개이며 각 클래스 내 CVE는 구분한다. 시험 인용 문장과 같은 학습 문장은 제외하도록 보호한다. 학습 코드는 시험 라벨이나 시험 예측을 읽지 않는다.

모델은 고정된 Qwen2.5-Coder-14B의 4비트 양자화 베이스이며 QLoRA rank 4, `q_proj/v_proj`, 1 epoch, 64 optimizer 업데이트다. 최종 체크포인트 하나를 고정하고 시험 점수로 선택하지 않는다. 입력·출력 임베딩 메모리 정책과 학습 가중치 전후 해시를 기록한다. 모델은 실제로 `A/U` 다음 토큰을 선택한다. 두 로짓은 보정된 확률로 표시하지 않는다.

기존 #3 어댑터를 덮어쓰지 않는다. 서비스는 동일한 베이스를 공유해 #4 어댑터로 전환했다가 성공·실패 모두 기존 식별 어댑터로 복원한다.

## 평가 지표

`results/item4_source_context_v1/precision_report.json`에서 전체·학습·시험 구간을 따로 확인한다. 원시 모델과 모델+논리 검증기 결과도 구분한다.

정밀도는 자동 `affected` 결정의 `TP/(TP+FP)`이며 **0.85 초과**가 기준이다. 양성 출력에 미주석 라벨이 있으면 완전한 정밀도를 제공하지 않고 보수적 하한도 계산한다. 양성 출력이 없으면 통과하지 않는다. 보류를 포함한 재현율·보류율·원문 경로 커버리지·실제 모델 호출 수를 함께 보고한다.

검증기 결합 점수가 높다는 것만으로 LLM 단독 판단이나 원문 추출의 정확도를 주장하지 않는다. 데이터가 부족해 보류한 9,966개 CVE를 알려진 음성으로 바꾸지 않는다. 학습 구간을 포함한 전체 결과를 독립 시험 성능으로 부르지 않는다. 서로 연결된 advisory 그룹과 반복된 운영상태가 있으므로 CVE/사례 수를 독립적인 실증 표본 수로 해석하지 않는다.

## 실행 및 서비스

```powershell
python tools/build_item4_source_context_gold.py
python tools/audit_item4_source_context.py
python tools/train_item4_source_context.py prepare
python tools/train_item4_source_context.py train
python tools/evaluate_item4_source_context.py
```

이미 동결된 Gold와 모델은 생성기가 덮어쓰지 않는다. 평가기는 모델·Gold·코드 해시가 같을 때만 저장한 예측에서 재개한다. 예측을 모두 저장한 뒤에만 평가 라벨을 읽는다.

* `GET /api/precision/item4/source-simulation/cves/{cve}`: 원문과 합성 사례·봉인된 예측 조회. Gold 라벨은 응답에 넣지 않는다.
* `POST /api/precision/item4/source-simulation/assess`: 원본 경로·제품·인용 스냅샷을 검증한 후 조건부 합성 세계 재평가. 실제 VEX 내보내기는 허용하지 않는다.
* `/precision.html`: 전수 자료 범위, 조건부 시험 점수, 실제 설비 검증 미측정 상태와 CVE별 근거 조회.

NIST Vulntology의 원문/제품/경로 표현과 ATT&CK ICS 자산 맥락은 사실 추적에 사용한다. 기존 OVAL 관측 가져오기와 MulVAL 공격 그래프 기능도 유지한다. 어느 도구의 분류나 경로 유무도 이 합성 가정을 실제 CVE의 충분조건 또는 실제 설비의 정답으로 승인하지 않는다.

## 최종 별도 시험 결과

4,012개 시험 CVE의 6,797개 사례 전체를 평가했습니다. 잠재 영향 라벨이 있는 합성 사례는 3,342건이며, 원문 미확정 시험 CVE 3,455개도 사례에 포함합니다. 모델 단독 TP 514·FP 6·Precision 98.846%, 결합 TP 508·FP 0·Precision 100%입니다. 결합 재현율은 30.40%, 보류율은 92.53%입니다. 관측으로 입증 가능한 양성 세계 557개 중 508개를 회수했습니다(91.20%). 이 보조 수치를 보류를 포함한 전체 재현율 대신 사용하지 않습니다. 검증기는 근거가 충족되지 않은 모델 양성 12개를 보류로 전환했습니다.

원시 예측·독립 Gold 재채점과 모델/데이터/코드 해시 검증이 통과했습니다. 서비스의 실제 새 어댑터 추론과 기존 식별 어댑터 복원도 확인했습니다. 실제 설비 영향 또는 원문 의미 정확도 검증은 이 합성 시험의 결과에 포함하지 않습니다.

이 보조 모델은 `A`(조건부 영향 확정)와 `U`(보류)의 두 가지 결정을 학습합니다. 선택 경로 조건이 거짓인 경우도 전체 실제 CVE의 `not_affected` 승인으로 바꾸지 않습니다. 운영용 `fixed`·`not_affected`는 기존 운영맥락 판단기의 별도 근거 검증을 사용합니다.
