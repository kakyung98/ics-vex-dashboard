# #4 실제 CVE 기반 합성 자산 운영 정보 평가

## 현재 제품별 근거 Gold — v5 (2026-11-18)

현재 기준은 `benchmark/item4_source_context_gold_v5/`와 `results/item4_source_context_v3_grounded_full_population/`다. v4에서 발견한 제품별 조건 및 자산 유형 연결 문제를 수량 유지용 가정으로 덮지 않고 수정한다.

원본 CSAF의 해시, CVE별 known_affected 제품 ID, 제품 트리의 이름·버전 범위를 연결한다. `For <product>` note 제목을 복원하여 해당 제품의 조건을 분리하고 일반 설명에서는 그 제품을 제외한다. 제목의 제품·버전 한정이 불명확하면 범위를 확대하지 않는다. NVD 설명에 제품별 CSAF 범위가 없으면 확정 경로 근거로 사용하지 않는다.

자산 역할은 제품 자체의 명시적 이름, 제품 범위가 확인된 원문의 역할 표현, 보존한 공식 공급사 설명으로만 연결한다. 탐색용 모델 배정과 제품의 상위 장비·호스트 이름은 Gold 유형으로 쓰지 않는다. 통신 부품은 원문 역할을 보존하되 고정 18개 분류에 맞지 않는 상위 유형은 미확정으로 남긴다. 기존 18개 ID·정의는 변경하지 않는다.

질문은 관측 가능한 제한된 술어와 일치해야 한다. 예/아니오/모름 대응, 원문 구절·한정·부정, AND/OR/NOT을 검사한다. 지원하지 않는 조건이나 모호한 결합, 공격자의 자격증명·메모리 상태는 참으로 가정하지 않고 해당 경로를 미확정으로 남긴다. 제품별 원문과 역할·질문 근거는 전체 제품 인덱스에 보존한다.

이 기준으로 조건 사례를 구성할 수 있는 CVE는 6개이며 나머지 12,412개는 미확정이다. 총 12,436건 전부를 실제 모델에 보낸다. 별도 시험 구간에는 확정 양성이 없으므로 그 구간의 영향 Precision을 100%로 표시하거나 목표 통과로 판정하지 않는다. 미확정 영향은 null이며 음성으로 바꾸지 않는다.

이 수량은 현재 자동 계약의 지원 범위다. 원문이 실제로 충분한 모든 CVE의 총수가 아니다. 자료 부족 외에도 지원하지 않는 질문 술어, 제품 범위·자산 역할·논리 해석을 확정하지 못한 경우를 미확정으로 유지한다.

최종 실행 `20261118_product_source_gold_v5_final`에서 12,418개 모두 실제 추론했고 12,436개 출력을 저장·재채점했다. 확정 사례는 모두 학습 구간에 있어 전체 TP 6·FP 0을 독립 시험 Precision으로 해석하지 않는다. 별도 시험 4,012개는 모두 미확정이며 Precision/Recall은 null, 시험 목표 통과는 false다. 코드 회귀 테스트 25개와 전체 원문·제품·자산 역할 재구성 및 질문/조건식 계약 검사가 통과했다. 근거와 네 사례는 [추적 예시](../results/item4_source_context_v3_grounded_full_population/examples/CVE-2015-8214.json)에 보존한다.

자동 근거 계약 검사와 코드 회귀 테스트는 독립적인 사람의 의미 정확도 검증이 아니다. 관측은 합성이고 실제 운영자 답변이나 실제 설비 영향 Gold는 수집하지 않았다. 모든 다른 공격 경로의 부재나 충분조건을 실증한 것은 아니므로 결과는 선택 제품·경로의 조건부 합성 판단으로 제한한다.

```powershell

python -X utf8 tools/run_item4_source_context_h200.py --run-id 20261118_product_source_gold_v5_final status
python -X utf8 tools/run_item4_source_context_h200.py --run-id 20261118_product_source_gold_v5_final fetch
```

새 실행에서는 고유 run ID와 `--build-gold start`를 사용한다. 원본·모델은 기존 H200 프로젝트에서 읽고 새 Gold·감사·예측은 별도 실행 디렉터리에 저장한다. 동일 체크포인트를 동결하며 시험 점수로 재학습·선택하지 않는다.

## 이전 전수 평가 — v4 (2026-11-18)

`benchmark/item4_source_context_gold_v4/`는 충돌·만료를 제외한 네 변형을 유지하면서 누락된 원문 경로를 다시 추출한 데이터다. 기존 2,452개에 848개를 추가해 3,300개 CVE에 조건 기반 네 사례(13,200건)를 구성했다. 나머지 9,118개 CVE는 원문과 미확정 사유가 있는 사례로 유지한다. 총 22,318건이며 학습 구간 16,266건, 시험 구간 6,052건이다. CVE 분할은 8,406/4,012개로 유지한다.

**12,418개 CVE 모두 실제 모델 추론을 받아야 전수 평가 완료로 인정한다.** 경로가 없을 때 `U`를 하드코딩하고 모델 호출을 생략하던 동작을 제거했다. 원문이 있는 미확정 사례도 모델에 전달하며 `actual_affected=null`은 유지한다. 모델이 이런 사례를 영향으로 출력하면 알려진 음성으로 채점하지 않고 `unjudged_positive`로 집계한다. 영향 Precision과 별도로 미확정 보류율 및 `A/U` 결정 정확도를 보고한다. 전수 추론은 모든 CVE의 실제 영향 정답을 확보했다는 뜻이 아니다.

원문 복구는 문장 뒤쪽의 `allows remote attackers ...`, `local users` 등 접근 표현과 누락된 관측 가능 설정 조건을 처리한다. 명시적인 설정/AND/OR 조건을 접근 조건 하나로 덮어쓰지 않는다. 인증된 사용자라는 전제는 접근 가능 여부와 분리한 관측 불가 가정으로 보존한다. 복구한 경로는 원문 인용과 제품 연결을 보존한 미검토 초안이며 독립 의미 정확도는 검증하지 않았다. 기존 원문 레코드는 변경하지 않고 Gold 내부 파생 스냅샷에 원래 레코드 해시를 남긴다.

v4 무결성 검사는 통과했으며 최대 입력은 3,059토큰이다. 기존 분할을 유지한 상태에서 선택 인용문 해시 6개가 학습/시험 구간에 중복된다. 새 모델을 학습하지 않고 기존 동결 어댑터를 평가하며, 실제 어댑터 학습 예제와 시험 인용문 사이의 중복도 별도 재검증한다. 분할 간 원문 중복이 0개라고 주장하지 않는다.

새 결과는 `results/item4_source_context_v2_full_population/`에 저장한다. 기존 학습 Gold/코드 해시와 새 평가 Gold/코드 해시를 구분해서 기록하며, 모델 메타데이터나 과거 점수를 수정하지 않는다. 기존 어댑터를 다시 평가하는 작업이며 재학습은 수행하지 않는다. 전수에는 학습 출신 CVE도 포함되므로 별도 시험 구간 결과를 함께 보고한다.

```powershell

python tools/audit_item4_source_context.py
python tools/run_item4_source_context_h200.py --run-id 20261118_four_worlds_full_population_v4_qualified start

python tools/run_item4_source_context_h200.py --run-id 20261118_four_worlds_full_population_v4_qualified fetch
```

H200 실행기는 기존 서비스와 모델을 변경하지 않는 별도 디렉터리를 사용한다. 실제 추론 전체 완료와 원시 예측 재채점이 끝난 뒤에만 완료 결과를 내려받는다.

전수 재평가는 완료했다. 실제 모델 호출 22,318건, 모델 추론을 받은 CVE 12,418개이며 저장 예측 재채점과 모델/입력/코드 해시 검증이 통과했다. 실제 어댑터 학습 예제와 시험 인용문 사이의 정확 문장 중복은 0개다. 코드 회귀 테스트 9개가 통과했다.

| 구간 | 모델 단독 Precision | 모델+검증 Precision | 결합 잠재 영향 Recall | 결합 보류율 |

| 별도 시험 4,012 CVE / 6,052건 | 99.0640% | 100% | 46.25% | 89.6067% |

근거 부족 9,118개 CVE도 모두 실제 추론했고 전부 보류했다. 이들의 잠재 영향 정답은 null로 유지한다. 잠재 영향 Recall은 핵심 조건이 숨겨진 참 세계까지 분모에 포함하므로, 네 변형 구성에서 관측으로 확정 가능한 양성만 회수하면 최대 50%다.

**원문-제품 의미 연결의 미해결 사례도 확인됐다.** CVE-2015-8214는 일반 TCP/102 조건을 CP 342-5에 연결했지만 원문에는 이 제품의 PROFIBUS 접근 조건이 별도로 존재한다. Gold 자산 유형도 빈 값이고 탐색용 Routers 분류는 모델 추정이다. 실제 운영자 답변은 수집하지 않았다. 이 사례와 근거는 [의미 검토 기록](../results/item4_source_context_v2_full_population/source_semantic_findings.json)에 보존한다. 수치가 높다는 이유로 이 Gold의 제품별 조건·자산 분류·실제 영향 정확도가 검증됐다고 해석하면 안 된다.

## 무엇을 평가하는가

고정 모집단은 실제 CVE **12,418개**다. 기존 가상 CVE 100개 논리 시험을 이 모집단의 성능으로 사용하지 않는다. 새 데이터는 각 CVE의 원문·제품·선택 경로·조건·관측 상태를 추적한다.

이 평가는 **원문 조건부 합성 세계**의 판단을 측정한다. 원문에서 자동 추출한 초안의 의미 정확도나 실제 설비의 영향 정확도를 측정하는 실증 평가는 아니다. 다음 가정은 현실의 사실로 승인한 것이 아니라 합성 세계의 정의다.

* 원문이 설명한 선택 경로를 이 세계에서는 완전한 경로로 취급한다.
* 선택한 원문 제품 후보에 해당 경로가 적용된다고 가정한다.
* 운영자가 관측할 수 없는 전제는 이 세계에서 충족됐다고 명시한다. 운영자에게 공격자의 실제 자격증명·익스플로잇·메모리 상태를 증명하도록 요구하지 않는다.
* 다른 공격 경로는 이 합성 세계에서만 제외한다.

따라서 결과는 실제 CVE 전체의 비영향 또는 영향 결론으로 내보낼 수 없다. API는 `is_production_VEX=false`, `export_allowed=false`를 반환한다. 원문 초안의 `pending` 상태와 의미 검증 미완료 표시는 유지한다. 사람의 의미 검토 승인을 자동 생성하지 않는다.

## 이전 네 변형 Gold — v3 (2026-11-18)

`benchmark/item4_source_context_gold_v3/`에 다음을 저장한다. 기존 v2의 충돌·만료 변형을 제외한 버전이다.

* `cve_source_records.jsonl`: 실제 CVE 12,418개 전체 원문·제품·초안. 원문 해시와 인용 위치를 보존한다.
* `cve_index.jsonl`: 모든 CVE의 분할·원문 경로·시험 사례 ID·미확정 사유.
* `train/inputs.jsonl`, `evaluation/inputs.jsonl`: 모델이 받을 수 있는 입력.
* `train/labels.jsonl`, `evaluation/labels.jsonl`: 모델에 전달하지 않는 독립 시뮬레이터 라벨.
* `manifest.json`, `integrity_audit.json`: 모집단·파일 해시·분할·원문 대조·정답 일관성·문맥 길이 검사.

v3는 총 **19,774건**(학습 14,091건·시험 5,683건)이다. **2,452개**는 당시 생성기의 요건을 통과한 CVE 수이며 실제로 구성 가능한 CVE의 총수를 뜻하지 않는다. 미확정 CVE는 **9,966개**다. 미확정 CVE는 삭제하지 않고 `under_investigation` 결정 라벨과 `actual_affected=null`을 가진 사례로 유지한다. 미확정 사유는 여러 개일 수 있으므로 사유별 수량은 합산 가능한 배타적 분류가 아니다.

관측 가능한 조건을 구별할 수 있는 경로마다 조건 충족/불충족 관측, 숨겨진 충족/불충족의 네 세계만 만든다. 충돌·만료는 Gold 생성에서 제외한다. 운영 판정기의 범위·충돌·유효시점 검사는 유지한다. 서로 다른 숨겨진 실제 상태가 같은 관측을 만들 수 있다. 이런 사례에서 적절한 결정은 보류다. ID·구성 ID는 불투명하며 잠재 상태·정답·변형 이름을 모델 입력에 넣지 않는다.

`v1`은 기존 원문 초안 7개에서 같은 조건 ID를 네트워크와 인증 조건에 함께 사용한 문제를 발견해 격리했다. 학습·모델 시험 시작 전에 독립 관측 정답 검사로 발견했으며, `v2`는 이런 경로를 의미 재구성 필요 상태로 보존한다. 점수를 보고 고른 데이터 버전이 아니다.

## 독립 정답 생성과 판정기

Gold 생성기는 Boolean 식을 DNF로 컴파일하고 합성 세계의 잠재 상태에서 영향 여부를 계산한다. 관측 가능한 사실만으로 모든 가능한 숨겨진 상태를 열거해, 모든 경우에 선택 경로가 참일 때만 `A`를 정답 결정으로 삼는다. 그 밖에는 `U`다.

실행 판정기는 별도의 3값 AND/OR/NOT 논리와 범위·시점 검사를 사용한다. Gold 생성에 이 판정기의 결과를 쓰지 않는다. 기존 v2 전체 24,678건에서 두 구현의 결정 일치와 `A`가 잠재 상태의 참과 모순되지 않는지를 모델 학습 전에 검사했다.

두 구현의 일치는 선언한 합성 세계의 논리 정확성을 검사한다. 원문이 현실의 충분조건을 완전히 설명한다는 독립 검증은 아니다. 이 차이를 정밀도 수치와 함께 표시한다.

## 기존 v2의 분할과 실제 QLoRA 학습

공유 원문 URL 연결 그룹을 유지한 기존 전체 모집단 분할을 쓴다. 학습 CVE **8,406개**, 시험 CVE **4,012개**다. 정확한 7:3이라고 표시하지 않는다. 두 구간의 CVE 및 선택 인용 문장 해시가 겹치지 않는 것을 검사했다.

새 #4 전용 어댑터는 학습 구간에서만 고정 해시 순서로 고른 **256개 예제**로 학습했다. `A/U` 각각 128개이며 각 클래스 내 CVE는 구분한다. 시험 인용 문장과 같은 학습 문장은 제외하도록 보호한다. 학습 코드는 시험 라벨이나 시험 예측을 읽지 않는다.

모델은 고정된 Qwen2.5-Coder-14B의 4비트 양자화 베이스이며 QLoRA rank 4, `q_proj/v_proj`, 1 epoch, 64 optimizer 업데이트다. 최종 체크포인트 하나를 고정하고 시험 점수로 선택하지 않는다. 입력·출력 임베딩 메모리 정책과 학습 가중치 전후 해시를 기록한다. 모델은 실제로 `A/U` 다음 토큰을 선택한다. 두 로짓은 보정된 확률로 표시하지 않는다.

기존 #3 어댑터를 덮어쓰지 않는다. 서비스는 동일한 베이스를 공유해 #4 어댑터로 전환했다가 성공·실패 모두 기존 식별 어댑터로 복원한다.

## 평가 지표

`results/item4_source_context_v1/precision_report.json`은 충돌·만료를 포함한 기존 v2의 결과다. v3/v4의 점수로 인용하지 않는다. 기존 보고서에서는 전체·학습·시험 구간을 따로 확인한다. 원시 모델과 모델+논리 검증기 결과도 구분한다.

정밀도는 자동 `affected` 결정의 `TP/(TP+FP)`이며 **0.85 초과**가 기준이다. 양성 출력에 미주석 라벨이 있으면 완전한 정밀도를 제공하지 않고 보수적 하한도 계산한다. 양성 출력이 없으면 통과하지 않는다. 보류를 포함한 재현율·보류율·원문 경로 커버리지·실제 모델 호출 수를 함께 보고한다.

검증기 결합 점수가 높다는 것만으로 LLM 단독 판단이나 원문 추출의 정확도를 주장하지 않는다. 데이터가 부족해 보류한 9,966개 CVE를 알려진 음성으로 바꾸지 않는다. 학습 구간을 포함한 전체 결과를 독립 시험 성능으로 부르지 않는다. 서로 연결된 advisory 그룹과 반복된 운영상태가 있으므로 CVE/사례 수를 독립적인 실증 표본 수로 해석하지 않는다.

## 실행 및 서비스

```powershell
python tools/build_item4_source_context_gold.py
python tools/audit_item4_source_context.py
python tools/train_item4_source_context.py prepare
python tools/train_item4_source_context.py train
python tools/evaluate_item4_source_context.py
```

이미 동결된 Gold와 모델은 생성기가 덮어쓰지 않는다. 평가기는 모델·Gold·코드 해시가 같을 때만 저장한 예측에서 재개한다. 예측을 모두 저장한 뒤에만 평가 라벨을 읽는다.

* `GET /api/precision/item4/source-simulation/cves/{cve}`: 원문과 합성 사례·봉인된 예측 조회. Gold 라벨은 응답에 넣지 않는다.
* `POST /api/precision/item4/source-simulation/assess`: 원본 경로·제품·인용 스냅샷을 검증한 후 조건부 합성 세계 재평가. 실제 VEX 내보내기는 허용하지 않는다.
* `/precision.html`: 전수 자료 범위, 조건부 시험 점수, 실제 설비 검증 미측정 상태와 CVE별 근거 조회.

NIST Vulntology의 원문/제품/경로 표현과 ATT&CK ICS 자산 맥락은 사실 추적에 사용한다. 기존 OVAL 관측 가져오기와 MulVAL 공격 그래프 기능도 유지한다. 어느 도구의 분류나 경로 유무도 이 합성 가정을 실제 CVE의 충분조건 또는 실제 설비의 정답으로 승인하지 않는다.

## 기존 v2 별도 시험 결과 — 6가지 변형

4,012개 시험 CVE의 6,797개 사례 전체를 평가했습니다. 잠재 영향 라벨이 있는 합성 사례는 3,342건이며, 원문 미확정 시험 CVE 3,455개도 사례에 포함합니다. 모델 단독 TP 514·FP 6·Precision 98.846%, 결합 TP 508·FP 0·Precision 100%입니다. 결합 재현율은 30.40%, 보류율은 92.53%입니다. 관측으로 입증 가능한 양성 세계 557개 중 508개를 회수했습니다(91.20%). 이 보조 수치를 보류를 포함한 전체 재현율 대신 사용하지 않습니다. 검증기는 근거가 충족되지 않은 모델 양성 12개를 보류로 전환했습니다.

원시 예측·독립 Gold 재채점과 모델/데이터/코드 해시 검증이 통과했습니다. 서비스의 실제 새 어댑터 추론과 기존 식별 어댑터 복원도 확인했습니다. 실제 설비 영향 또는 원문 의미 정확도 검증은 이 합성 시험의 결과에 포함하지 않습니다.

이 보조 모델은 `A`(조건부 영향 확정)와 `U`(보류)의 두 가지 결정을 학습합니다. 선택 경로 조건이 거짓인 경우도 전체 실제 CVE의 `not_affected` 승인으로 바꾸지 않습니다. 운영용 `fixed`·`not_affected`는 기존 자산 운영 정보 판단기의 별도 근거 검증을 사용합니다.
