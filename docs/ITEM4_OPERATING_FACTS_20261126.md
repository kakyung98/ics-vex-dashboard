# Item 4 operating facts: 2026-11-26

운영자가 공격자 위치나 악용 경로 존재를 추측하지 않도록 입력 계약을 변경했다.

## 자산 설정

- 평가 범위는 현재 동일 자산·구성인지 확인한다.
- 운전 모드는 추가 입력으로 접어 두며 정상 운전·유지보수·기동/정지·Unknown 중 하나만 선택한다. 모드가 다르면 평가를 나눈다. 모드 자체를 CVE 악용 조건으로 추정하지 않는다.
- 설치 여부를 먼저 확인한다. 설치됨일 때 실제 버전 확인을 표시하고, 미설치일 때 자산 목록의 완전성을 표시한다.
- 서버도 조건에 맞지 않는 숨겨진 입력을 Unknown으로 정규화한다. BOM 버전만으로 실제 설치 버전을 확인했다고 간주하지 않는다.

## CVSS 기반 사실 수집과 판단

네트워크 질문은 CVE 대상 인터페이스·프로토콜에 관한 현재 기록을 입력받는다. 같은 OT 구역, 업무 IT망, 인터넷, 원격 유지보수/VPN을 복수 선택할 수 있다.

| 입력 | 저장 | 접근 조건 평가 |
|---|---|---|
| 현재 접근 규칙이 선택한 구역의 접속을 허용 | `allowed:<zones>` | Unknown: 규칙만으로 실제 연결을 증명하지 않음 |
| 기존 기록에 선택한 구역에서 해당 인터페이스로의 성공 접속이 확인됨 | `zones:<zones>` | true: 해당 접근 전제만 충족. 악용 성공이나 제품 영향 확정 아님 |
| 모든 관련 인터페이스·경로와 나열된 구역의 차단이 완전한 현재 기록으로 확인됨 | `x` | false: 알려진 접근 전제만 차단. 제품 비영향 확정 아님 |
| 기록 없음·대상 불명확·부분 확인·상충 | `unknown` / `mixed` / `not_applicable` | Unknown |

미선택 구역은 차단으로 처리하지 않는다. 인접 접근(AV:A)은 원문이 요구한 인접성을 확인해야 하며 일반적인 라우팅 연결만으로 대체하지 않는다. 운영자에게 새 스캔이나 익스플로잇 실행을 요구하지 않는다.

PR:N과 UI:N은 해당 벡터에서 선행 권한/사용자 동작을 요구하지 않으므로 질문을 생성하지 않는다. 이는 인증이 비활성화되었다는 뜻이 아니다. PR:L/H는 접근제어·사고 기록으로 확인된 비인가 주체의 권한만 근거로 삼으며 서비스 계정의 존재를 공격자 권한으로 대체하지 않는다. UI는 원문에 특정된 사용자 동작을 확인한다. AC:H·AT:P의 구체적 조건은 원문 근거를 요구하고 추출되지 않았으면 Unknown을 유지한다. 영향 지표는 운영 전제 질문으로 만들지 않는다.

검사에 사용한 기존 11-CVE SBOM의 벡터 조합은 AV:N/PR:N/UI:N/AC:L 7건, AV:N/PR:N/UI:N/AC:H 2건, AV:N/PR:H/UI:N/AC:L 1건, AV:N/PR:N/UI:R/AC:L 1건이었다. 따라서 질문은 AV 11개, PR 1개, UI 1개다. 화면에서 벡터 전체와 질문 생략·미해결 이유를 구분한다.
