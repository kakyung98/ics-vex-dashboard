# 시험항목 #3·#4 평가 범위와 재현 방법

## 고정 평가 원칙

모델 입력에는 시험 라벨을 전달하지 않습니다. 최종 어댑터는 학습 종료 체크포인트 하나이며, 시험 정밀도로 선택하지 않습니다. 전체 시험 입력을 평가하고 누락·보류·오류를 기록합니다. 정밀도는 TP/(TP+FP)이며 출력이 없는 경우 목표 달성으로 처리하지 않습니다. #3은 0.80 **초과**, #4는 0.85 **초과**가 기준입니다.

#3은 선언된 구성요소와 CVE의 제품·버전·edition 매핑을 평가합니다. 공격 경로와 실행 환경 영향은 정답 범위에 포함하지 않습니다. 기준 Gold는 원문 조건의 기계 라벨이며 실제 설치 자산의 독립 실사 정답이 아닙니다.

#4는 운영맥락의 실제 영향 여부를 평가합니다. 현재 제공된 정답 자료는 가상 제품·상태에 대한 Boolean 시뮬레이터입니다. 원문 추출의 정확도, 실제 CVE의 충분조건 정확도, 실제 설비의 영향 정확도는 이 시뮬레이션 점수로 측정하지 않습니다. 별도의 실제 자산 라벨 양식을 제공하며 실제 Precision은 미측정으로 유지합니다.

## 데이터와 학습

* #3 Gold: `benchmark/item3_gold_v11`, CVE 기준 7,593/3,254개, 입력 83,112/18,608건. 입력과 라벨은 다른 JSONL 파일입니다.
* #4 현재 Gold: `benchmark/item4_operational_gold_v2`, 가상 취약점·제품 그룹 70/30개, 입력 4,480/1,920건. AND·OR·NOT 네 가지 식과 8가지 상태, 8가지 관측 품질 변형을 포함합니다.
* #4 v1 식별자에는 관측 상태 비트가 포함되어 있어 보류 사례의 시험에 부적절합니다. v2는 사례·구성·관측 출처의 식별자를 SHA256 기반 불투명 문자열로 바꾸었습니다. v2 시험 추론 전에 수정했으며 v1과 기존 학습 산출물은 이력으로 보존합니다.
* 공유 어댑터의 운영맥락 학습 32개는 v1의 **모든 관측이 제공된 complete 학습 사례**입니다. 상태를 감춘 v1 시험 사례로 평가하거나 선택하지 않습니다. 고정 어댑터를 v2 시험 입력에 적용합니다.
* 실제 QLoRA 학습량은 P2·P3·P4·운영맥락 각각 32개, 총 128개·1 epoch·32 optimizer 업데이트입니다. 분할 전체를 학습한 것으로 표시하지 않습니다.

`tools/audit_operational_gold.py`는 v2 파일 해시, 입력·정답의 범위 일치, 고유 불투명 ID, 입력 내 정답 키 부재, 그룹 분리와 수량을 검증합니다. 인용의 의미 정확도와 현실의 사실성을 검증하는 프로그램은 아닙니다.

## 평가 산출물

#3의 `results/item3_precision_v11/trained_evaluation`에는 입력 전체의 예측 SQLite, 패킷 캐시, 모델·데이터·코드 해시를 기록한 실행 설정, 진행 상태 및 최종 보고서가 저장됩니다. 같은 패킷의 결과 재사용과 실제 모델 호출을 구분합니다. 다른 모델·데이터·코드로 재개하면 실행을 거부합니다.

#4는 출처·범위·관측 유효성 판단을 먼저 수행하고, affected 자격을 갖춘 경우에만 학습 모델의 제안을 구합니다. 모델이 동의하지 않으면 보류합니다. 모델은 증거가 부족한 사례를 affected로 승격할 수 없습니다. 전체 1,920건의 결과에 대해 정밀도와 보류를 포함한 재현율을 계산합니다. 이 구조는 정밀도를 높이면서 재현율을 낮출 수 있으므로 보류율을 반드시 함께 보고합니다.

기본 합성 자료에 대한 판단기 단독 결과는 TP 285, FP 0, FN 590, Precision 1.0, recall 약 0.326, abstention 약 0.852입니다. 최종 모델 결합 결과는 별도 `trained_precision_report.json`으로 확인합니다.

## 표준과 도구의 증거 범위

NIST Vulntology 스키마 검증은 표현 형식을 검사합니다. ATT&CK ICS 자산·기법 분류는 질문을 찾기 위한 맥락입니다. 어느 것도 CVE별 필수조건·충분조건의 사실성을 자동 보증하지 않습니다.

OVAL 결과는 정확한 자산과 정의 ID에 연결하며 오류·미평가·지원되지 않는 상태는 unknown입니다. MulVAL은 출처가 확인된 사실로 경로를 계산합니다. 경로 미발견은 비영향 증거가 아닙니다. Docker 실행 검증 자료는 `results/operational_tools_v1`에 저장하며 실제 ICS 장치를 스캔한 결과로 취급하지 않습니다.

## 실제 자산 평가

`real_asset_annotation_blank.json`의 자산·제품·실행 빌드·구성·운영 모드·공격 출발점·평가 시점을 기록합니다. 예측을 보지 않은 독립 검토자 두 명이 근거와 영향 정답을 기록하고 불일치는 별도 검토자가 조정합니다. 자료가 없거나 불충분하면 null로 남깁니다. `src/item4_scoring.py`는 완전히 같은 범위 모집단을 요구하고, 미주석 affected 출력이 있으면 완전한 Precision을 제공하지 않습니다.
