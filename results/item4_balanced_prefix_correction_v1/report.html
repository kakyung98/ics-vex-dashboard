기존 balanced_views는 [기존 혼합 입력 128차원, CISA context 128차원] 순서입니다. 앞쪽 16/32/64/128개를 단순 선택하면 기존 혼합 입력만 남습니다. 해당 raw-prefix 결과를 두 입력 결합 효과로 해석하면 안 됩니다. 전체 256차원을 입력받은 DAE·대조학습과 raw256은 두 입력을 모두 사용하므로 이 문제와 구분합니다.
