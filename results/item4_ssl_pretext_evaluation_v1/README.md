# 자기지도 대조학습 모델의 과제 평가

기존 실험의 Silhouette·ARI는 군집의 분리도·안정성 평가였다. 학습 손실 감소와 가중치 변화도 확인했지만, 그것만으로 시험 자료에서의 자기지도 과제 성능을 검증한 것은 아니었다. 이번에는 기존 CISA 후보와 같은 이웃 기반 대조학습 알고리즘을 **평가용으로 별도 재학습**해 입력으로 만든 정답 쌍을 판별했다. 기존 전수 학습 모델을 새 시험 자료에서 검증한 것으로 해석하지 않는다.

## 분리와 학습

- 전체 12,418개 CVE를 학습 8,692 / 검증 1,863 / 시험 1,863개로 나누고 전부 분할 원장에 보존했다. 기존 전수 군집 CSV도 그대로 유지했다.
- 같은 CISA 권고문을 공유하는 CVE를 연결 성분으로 묶었다. 동일 문서 내용도 같은 그룹에 포함했다. 학습·검증·시험 사이의 권고문 ID·동일 문서·동일 투영 입력 벡터 중복은 각각 0이다. 투영 후 중복 1개 그룹은 같은 분할로 합쳐 전처리를 다시 학습했다. 이는 점수 확인 전 분할 정제이며, 시간·업체별 외삽 평가를 뜻하지 않는다.
- TF-IDF/SVD256과 인코더 모두 **학습 권고문만** 사용해 적합했다. 각 CVE의 관련 권고문 벡터를 평균 후 정규화했다. 유일 입력 벡터 수는 학습 1,815 / 검증 1,053 / 시험 1,057개다. 여러 CVE가 동일 권고문 표현을 공유하므로 평가 단위는 CVE 분류가 아니라 유일 입력 벡터의 쌍이다.
- 무작위 초기화 MLP 256→512→128→16, 이웃 양성 대칭 InfoNCE + 0.1 코사인 관계 MSE, 입력 특징 10% 마스킹, 온도 0.1, Adam 0.0003, 배치 256, 50 epoch, seed 42. GPU RTX 4070 Ti SUPER를 사용했다. LLM·사전학습 언어 모델·CWE 라벨을 사용하지 않았다.

## 시험 과제

각 분할 내부 원본 벡터의 가장 가까운 5개 이웃을 양성으로 정의했다. 음성은 이웃 밖에서 무작위로 고른 5개 또는 가까운 순위 6~50에서 고른 5개다. 각 유형의 양성·음성 수는 같다. 평가 입력 양쪽에 독립적인 10% 마스킹을 적용하고 정규화했다. 모델마다 검증 자료의 혼합 F1이 최대인 코사인 유사도 임계값을 1,001개 분위수에서 선택하고, 시험 자료에는 고정 적용했다. 시험 점수로 모델이나 임계값을 고르지 않았다.

시험 혼합 쌍은 21,140개다. 무작위·어려운 음성 유형별로 10,570개이며, 유형 사이에 양성 쌍은 재사용된다. 같은 앵커가 반복되므로 쌍을 독립 표본으로 간주하지 않는다. 아래 수치는 한 분할·한 학습 seed·한 평가 마스크 추출의 결과이며 반복 신뢰구간은 계산하지 않았다.

| 표현 / 시험 조건 | Accuracy | Precision | Recall | F1 |
| --- | ---: | ---: | ---: | ---: |
| 원본 SVD256 / 혼합 | 0.8099 | 0.7524 | 0.9237 | 0.8293 |
| 학습 전 인코더16 / 혼합 | 0.6753 | 0.6261 | 0.8702 | 0.7283 |
| **학습한 인코더16 / 혼합** | **0.7784** | **0.7143** | **0.9281** | **0.8073** |
| 학습한 인코더16 / 무작위 음성 | 0.9168 | 0.9077 | 0.9281 | 0.9178 |
| 학습한 인코더16 / 어려운 음성 | 0.6400 | 0.5888 | 0.9281 | 0.7205 |

학습한 인코더의 임계값은 0.4166136558055878이다. 학습 전보다 혼합 F1은 증가했으나 원본 SVD의 혼합 F1보다 낮다. 양성 정답을 원본 공간의 이웃으로 정의했으므로 원본 기준선에 유리한 평가다. 혼합 ROC-AUC는 학습 인코더 0.8810, 원본 0.8724이며 임계값 기반 F1과 평가하는 성질이 다르다.

**이 수치는 자기지도 이웃 쌍 판별 성능이다. 실제로 같은 취약점 유형이라는 독립 정답이 아니며, CWE 분류·군집 의미 정확도·VEX 판단 정확도로 해석하지 않는다.** 외부 의미 평가에는 별도 참조 정답이 필요하지만, 이번 자기지도 과제 평가는 입력에서 만든 정답으로 수행 가능하다.

## 저장 파일

- `metrics.json`: 정확한 지표, 검증 임계값, 혼동행렬, ROC-AUC.
- `protocol.json`, `split_audit.json`, `cve_split_ledger.jsonl`: 설정·출처 해시·전수 분할·누출 검사.
- `validation_pairs.jsonl`, `test_pairs.jsonl`: 양성/음성 정답과 세 표현의 점수. 인덱스는 해당 `*_unique_inputs.npy` 행을 가리킨다.
- `all_cve_inputs.npy`: 분할 원장의 순서대로 전체 12,418개 입력 벡터.
- `train_only_preprocessing.joblib`, `evaluation_only_model.pt`, `training_history.json`: 재현용 전처리·평가용 가중치·학습 기록. 기존 전수 군집 모델을 대체하지 않는다.
- 실행 코드: `tools/evaluate_item4_ssl_pretext.py`. 검증 코드: `tools/verify_item4_ssl_pretext.py`.
