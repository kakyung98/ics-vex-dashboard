Paste / upload / drag a CycloneDX SBOM. Source-available CVEs are judged directly; source-uncollectable CVEs continue into the decision tree below.




CPE normalization — exact vs Ratcliff–Obershelp

Each SBOM component is fuzzy-matched to a CPE with the Ratcliff–Obershelp similarity (Python difflib); CVEs are re-identified from the normalized CPE and compared to the exact-match CVEs.

Similarity threshold 0.70 · components below it stay unmatched (closest CPE still shown)

VEX decision tree — source-uncollectable CVEs

These CVEs' source cannot be obtained (closed firmware / no OSS code), so VEX is decided by the operational decision tree, branched by each CVE's CVSS attack vector. Answer each question Yes/No; every CVE is walked independently.
